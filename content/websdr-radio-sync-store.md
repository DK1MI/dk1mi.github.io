---
title: Web SDR → Radio Sync now available in the Chrome Web Store
date: 2026-11-16 10:00
---

The [Web SDR → Radio Sync Chrome Browser Extension](https://rz01.org/websdr-radio-sync/) is now available in the Chrome Web Store. To install it, simply [click here](https://chromewebstore.google.com/detail/web-sdr-%E2%86%92-radio-sync/ijdhjmmjgenlhgceppmhopmajkjigfhh), then click on "Add to Chrome".

More info on this project can be found on the project page on GitHub: <https://github.com/DK1MI/websdr-radio-sync>.
